# Data

The PDFs are not stored in this repository. Download them  and place them in `data/pdfs/` (git-ignored).

## Naming convention

```
<company>_<year>_<doc_type>.pdf
```

The ingestion script parses company, year and doc_type from the file name, so keep it exact.

## Notes

- All documents are the English versions.
- These reports are published by the companies for investors; check each site's terms before redistributing.
